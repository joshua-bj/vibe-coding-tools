# 电梯速度方向计算方案

## 1. 背景

在电梯场景中，Android 设备固定安装在电梯轿厢上，需要实时计算电梯的运行速度及方向（上行/下行）。

### 关键约束条件

- **设备固定不动**：设备与电梯刚性连接，不存在手持抖动、人体运动等干扰
- **运动模式单一**：电梯只有上行和下行两种运动方向，且沿 Z 轴（竖直方向）
- **加速度特征明显**：电梯启动时有明确的加速阶段，匀速运行时加速度趋近于零，停止时有减速阶段

## 2. 物理模型

### 2.1 坐标系定义

```
        ↑ Z+ (天)
        |
        |
  ------+------ → X+
        |
        |
        ↓ Z- (地)
```

- **Z 轴**：竖直方向，正方向朝上
- **重力加速度 g**：沿 Z 轴负方向，大小约 9.81 m/s²
- **电梯加速度 a**：沿 Z 轴，上行时为正，下行时为负

### 2.2 传感器读数分析

使用 `TYPE_ACCELEROMETER`（含重力）时，Z 轴读数为：

```
sensorZ = -g + a_elevator
```

其中：
- `-g`：重力分量（设备静止时 Z ≈ -9.81）
- `a_elevator`：电梯本身的加速度

使用 `TYPE_LINEAR_ACCELERATION`（已去除重力）时：

```
sensorZ = a_elevator
```

### 2.3 电梯运动阶段分析

```
加速度 a
  ↑
  │     ┌───┐
  │     │加速│
  │     │   │
──┼─────┘   └─────────────┐───┐
  │                        │减速│
  │                        └───┘
  └──────────────────────────────→ 时间 t
     启动    匀速运行        减速    停止
```

| 阶段 | 加速度 a | 速度 v | 方向判断 |
|------|---------|--------|---------|
| 静止 | ≈ 0 | = 0 | 无方向 |
| 加速上行 | > 阈值 | 增加 | **上行** |
| 匀速上行 | ≈ 0 | 恒定 > 0 | **上行**（由速度方向决定） |
| 减速上行 | < 0 | 减少 > 0 | **上行**（速度仍为正） |
| 加速下行 | < 阈值 | 减少 | **下行** |
| 匀速下行 | ≈ 0 | 恒定 < 0 | **下行**（由速度方向决定） |
| 减速下行 | > 0 | 增加 < 0 | **下行**（速度仍为负） |

## 3. 计算流程

### 3.1 信号处理链

```
TYPE_ACCELEROMETER (Z轴, 含重力 -g)
        │
        ▼
   高通滤波 (1 Hz)
   同时去除重力分量和传感器零点漂移
   （重力是 DC 分量 = 0 Hz，低于截止频率，自然被滤除）
        │
        ▼
   积分 → 速度 (m/s)
   v(t) = v(t-1) + a(t) × dt
        │
        ▼
   漂移滤波 (0.1 Hz)
   去除积分累积漂移
        │
        ▼
   低通滤波 (5 Hz)
   平滑电梯振动引起的高频速度波动
   振动频率通常 > 10 Hz，不影响真实速度信号
        │
        ├──────────────────┐
        ▼                  ▼
   v_z(t) 用于显示       v_z_smooth(t) 用于方向判断
   （含振动细节）         （振动已滤除，方向稳定）
```

### 3.2 方向判断规则

使用经低通滤波后的平滑速度 `v_z_smooth` 判断方向（避免电梯振动导致方向频繁翻转）：

```java
if (|v_z_smooth| < NOISE_THRESHOLD) {
    direction = STATIONARY;  // 电梯静止
    speed = 0;
} else if (v_z > 0) {
    direction = UP;          // 上行
    speed = v_z;
} else {
    direction = DOWN;        // 下行
    speed = |v_z|;
}
```

**噪声阈值 NOISE_THRESHOLD**：电梯静止时，积分漂移和传感器噪声会导致速度有微小波动。典型值：`0.05 m/s`（即 50 mm/s）。低于此值视为静止。

### 3.3 速度单位转换

```
显示速度 (mm/s) = v_z × 1000
```

## 4. 为什么只需 Z 轴

在电梯场景中：

1. **运动方向固定**：电梯只沿竖直方向运动，X/Y 轴的理论加速度为零
2. **X/Y 仅为噪声**：任何 X/Y 轴读数都是传感器噪声或微小振动，不含运动信息
3. **简化计算**：单轴处理减少计算量和不必要的噪声放大

## 5. 为什么使用 TYPE_ACCELEROMETER

| 传感器类型 | Z 轴读数 | 优点 | 缺点 |
|-----------|---------|------|------|
| `TYPE_ACCELEROMETER` | `-g + a` | 数据原始，行为一致，跨设备可预测 | 含重力分量，需高通滤波去除 |
| `TYPE_LINEAR_ACCELERATION` | `a` | 硬件去除重力 | 厂商实现不一致，可能已内置高通滤波 |

**选择 `TYPE_ACCELEROMETER` 的理由**：

1. **高通滤波已可去除重力**：重力是 DC 分量（0 Hz），1 Hz 高通滤波器自然将其完全滤除，无需手动减去 g 值
2. **不受厂商实现差异影响**：`TYPE_LINEAR_ACCELERATION` 由各厂商自行实现去重力算法，不同设备行为可能不一致
3. **避免多重高通滤波**：`TYPE_LINEAR_ACCELERATION` 内部通常已包含高通滤波，再加上我们自己的高通滤波，会导致双重滤波引入相位失真和信号衰减

**信号处理对比**：

```
方案 A（本方案）：
TYPE_ACCELEROMETER → [HP 1Hz] → 积分 → [HP 0.1Hz] → 速度
  HP 滤波器去除：重力 + 零点漂移（一步完成）

方案 B（不推荐）：
TYPE_LINEAR_ACCELERATION → [HP 1Hz] → 积分 → [HP 0.1Hz] → 速度
  厂商内置 HP → 我们的 HP → 双重滤波，相位失真
```

## 6. 误差源及对策

| 误差源 | 原因 | 对策 |
|--------|------|------|
| 重力分量 | TYPE_ACCELEROMETER 包含 g | 高通滤波（1 Hz）一并去除 |
| 传感器零偏 | 传感器非理想，静止时输出不为零 | 高通滤波（1 Hz）一并去除 |
| 积分漂移 | 零偏残差经积分持续累积 | 速度漂移滤波（0.1 Hz） |
| 电梯振动 | 导轨摩擦、电机振动等引起高频加速度 | 低通滤波（5 Hz）平滑速度，用于方向判断 |
| 量化噪声 | ADC 分辨率有限 | 滤波 + 噪声阈值判断 |
| 温度漂移 | 传感器受温度影响 | 持续高通滤波可自适应 |
| 设备安装角度 | 设备 Z 轴未必完全竖直 | 校准或使用姿态传感器修正 |

## 7. 实现建议

### 7.1 参数配置

```java
SAMPLE_RATE      = 50 Hz (SENSOR_DELAY_UI)
HP_CUTOFF        = 1.0 Hz  (去除加速度零偏 + 重力)
DRIFT_CUTOFF     = 0.1 Hz  (去除速度积分漂移)
LP_CUTOFF        = 5.0 Hz  (平滑电梯振动，用于方向判断)
NOISE_THRESHOLD  = 0.05 m/s (静止判断阈值)
RMS_WINDOW       = 1.0 s    (RMS 计算窗口)
```

### 7.2 状态机

```
         ┌──────────┐
         │ STATIONARY│◄──────────────────┐
         └────┬─────┘                   │
    |v_z| > threshold            |v_z| < threshold
    v_z > 0 → UP                持续 0.5s
    v_z < 0 → DOWN              │
         │                       │
         ▼                       │
    ┌──────────┐                 │
    │ MOVING   │─────────────────┘
    │ UP/DOWN  │
    └──────────┘
```

- **STATIONARY → MOVING**：速度超过噪声阈值
- **MOVING → STATIONARY**：速度持续低于阈值超过 0.5 秒（防止短暂过零误判）

### 7.3 输出

```
┌─────────────────────────────────┐
│  ↑ 上行  速度: 1250 mm/s        │
│  ↕ 静止                        │
│  ↓ 下行  速度: 980 mm/s         │
└─────────────────────────────────┘
```

## 8. 注意事项

1. **重力去除**：使用 TYPE_ACCELEROMETER + 高通滤波，重力作为 DC 分量被自然滤除，无需手动减 g
2. **安装方向**：确保设备 Z 轴尽可能竖直，偏斜会导致加速度分量泄漏到 X/Y 轴
3. **采样率**：电梯加速度变化较慢，50 Hz 采样率足够，更高采样率不增加精度但增加计算量
4. **长时间漂移**：即使有漂移滤波，长时间运行（>10分钟）仍可能累积误差，建议在检测到静止状态时归零速度
